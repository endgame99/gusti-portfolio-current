# Design references

Optional source evidence for scoped design tasks. Start with [PRD](../PRD.md) and [UI contract](../UI_GUIDELINES.md). These captures are not application dependencies or business facts.

- `behance/`: captured CSS and layout notes.
- `ecommerce/`: PDP, marketplace, and Contoura/Taobao structural evidence.
- `zcool/`: work-detail capture and media manifest.

Load only a reference relevant to the active task. Preserve provenance; never treat external assets as GUSTI work. Superseded generic prompts and audit reports remain recoverable in Git history.
